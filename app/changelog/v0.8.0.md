### ✨ New Features

- ✨ All new encryption performed on the app will now use the Excalibur Encryption Format (ExEF) version 4
    - Read about the performance improvements below
- 🔧 Added new "file read chunk size" setting to configure file reading operations

### 🔄 Changes

- 💬 The displayed value of the file size will now _include_ the ExEF overhead (previously it would have been the raw plaintext size)

### ⚡️ Performance Improvements
