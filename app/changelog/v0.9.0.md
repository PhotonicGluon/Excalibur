## [v0.9.0](https://github.com/PhotonicGluon/Excalibur/tree/v0.9.0) - 2026-11-26

### 🔒️ Security

- 🔒️ Overridden version minima of dependencies in `pnpm-workspace.yaml` to address security vulnerabilities:

  - GHSA-wq5f-xc86-pv6w: `sharp` from `0.35.4` to `0.35.5` ([#225](https://github.com/PhotonicGluon/Excalibur/pull/225))
  - GHSA-68fv-2mgg-jv7q: `source-map-js` from `1.2.1` to `1.2.2` ([#225](https://github.com/PhotonicGluon/Excalibur/pull/225))

### ✨ New Features

- ✨ Added encrypted names to replace obfuscated names ([#342](https://github.com/PhotonicGluon/Excalibur/pull/342))
  - File and folder names are now encrypted before they leave the app, so the server can no longer see them.

- ✨ Added Merkle tree verification of vault data, improving security and data integrity. ([#203](https://github.com/PhotonicGluon/Excalibur/pull/203))
  - This includes a button to verify the full vault within the "data preferences" submenu, and to verify a single item within the ellipsis menu.

- ✨ Added the Electron version to the versions display in the sidebar

Existing users can upgrade their vault via a banner on the file explorer page. Names are encrypted first, and then the Merkle tree is built on top of them.

### 🔄 Changes

- 👔 Updated app to use the new ID-based file endpoints on the server instead of paths
- 👔 Changed search result ordering to be by similarity score first, then by name

### ⚡️ Performance Improvements

- ⚡️ Improved performance of the file uploading process by optimizing grouping all file existence checks together

  - This saves a lot of network traffic by reducing the number of API calls made to the server, and also reduces the amount of data transferred

## 🗑️ Removals

- 🗑️ Removed the obfuscated names option as it was replaced with encrypted names
