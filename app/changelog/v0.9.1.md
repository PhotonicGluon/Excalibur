## [v0.9.1](https://github.com/PhotonicGluon/Excalibur/tree/v0.9.1) - 2026-11-27

### ✨ New Features

- 🔧 Added setting to configure number of concurrent uploads

### 🔄 Changes

- ✨ Made drag-and-drop area cover the entire window
- 👔 Made some operations blocking while they are in progress; in particular:
  - Verifying files
  - Checking files before upload
  - Deleting files / folders
- 🚸 Made it so that username and password are cleared when the server is changed

### 🐛 Bug Fixes

- 🐛 Fixed an issue where uploading large folders would appear to hang and not upload
- 🐛 Fixed an issue where, if attempting to upload many (say, 1000) files, the browser will run out of memory, fail some jobs, and leave others stuck on pending

### ⚡️ Performance Improvements

- 🧱 Use a pool to limit the number of concurrent file uploads, improving stability and performance

### 🧹 Miscellaneous

- 👷 Updated GitHub actions' versions:

  - `actions/checkout` from `v6` to `v7`
  - `actions/setup-java` from `v5` to `v6`
  - `actions/setup-python` from `v6` to `v7`
  - `actions/download-artifact` from `v7` to `v8`
  - `actions/upload-artifact` from `v6` to `v7`
  - From `actions/attest-build-provenance@v3` to `actions/attest@v4`
  - `planetscale/ghcommit-action` from `v0.2.20` to `v0.2.22`
  - `astral-sh/setup-uv` from `v7` to `v10.4.0`
