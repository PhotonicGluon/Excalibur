Excalibur 0.6.4 is a patch release fixing a bug on the app and updating some dependencies.

Updating the app is recommended but not necessary. Updating the server is not required.

## App

#### 🐛 Bug Fixes

- 🐛 Fixed a bug where the name sorting was not ignoring the case (e.g., uppercase names were sorted before lowercase names of the same letter)

### ⬆️ Dependencies

- ⬆️ Updated `lint-staged` development dependency from `16.4.0` to `17.0.5` ([#29](https://github.com/PhotonicGluon/Excalibur/pull/29))

## Server

### ⬆️ Dependencies

- ⬆️ Updated `uvicorn` from `0.46.0` to `0.47.0` ([#24](https://github.com/PhotonicGluon/Excalibur/pull/24))
- ⬆️ Updated `ipython` development dependency from `9.10.1` to `9.13.0` ([#25](https://github.com/PhotonicGluon/Excalibur/pull/25))
- ⬆️ Updated `ruff` development dependency from `0.15.12` to `0.15.13` ([#28](https://github.com/PhotonicGluon/Excalibur/pull/28))
