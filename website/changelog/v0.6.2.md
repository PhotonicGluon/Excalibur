Excalibur 0.6.2 is a hotfix release fixing several bugs.

## App

### 🔄 Changes

- 💄 Enhanced obfuscation dialog with more information about the initial retrieval of items on the server

### 🐛 Bug Fixes

- 🐛 Fixed obfuscation process including an extra `.exef` in file names

## Server

### 🐛 Bug Fixes

- 🐛 Fixed an inconsistency where uploaded files must end in `.exef` but renaming files does not enforce this
    - Now, failure to provide an `.exef` extension when renaming a file will return a `417 Expectation Failed` error

- 🐛 Fixed backup command (`excalibur backup`) not including folders' contents
