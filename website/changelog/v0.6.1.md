Excalibur 0.6.1 is a hotfix release fixing a bug with name obfuscation on the app.

## App

### 🐛 Bug Fixes

- 🐛 Fixed an issue where trying to upgrade existing files to use obfuscated names would prematurely timeout if there are a lot of files to process

## Server

### ✨ New Features

- ✨ Added a new endpoint `/api/files/count` to count the number of items in the user's file system
