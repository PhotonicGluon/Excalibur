# Client Quickstart

Set up a client to connect to an Excalibur server.

:::important

This quickstart assumes that a [server](01-server.mdx) is already set up.

:::

## Installation

<Tabs groupId="platform">
    <TabItem value="windows" label="Windows">

    The Windows client can be obtained as an `.exe` installer.
    1. Download the `.exe` installer from <a href="/download?id=app-win-installer" target="_blank">here</a>.
    2. Double-click the `.exe` file to begin installation.
    3. After installation completes, Excalibur should open automatically.

    </TabItem>

    <TabItem value="macos" label="macOS">

    The macOS client can be obtained as either a `.dmg` file or a zipped `.app` file.
    - **Disk Image (`.dmg`)**:
        1. Download the `.dmg` file from <a href="/download?id=app-mac-dmg" target="_blank">here</a>.
        2. Double-click the `.dmg` file to open it.
        3. Drag the Excalibur application into the Applications folder.
    - **Zipped Application (`.zip`)**:
        1. Download the zipped `.app` file from <a href="/download?id=app-mac-app" target="_blank">here</a>.
        2. Extract the downloaded `.zip` file to obtain the Excalibur application.

    Double-click the Excalibur application to launch it.

    :::note["Excalibur Not Opened"]

    Due to Apple's security policy, you might see a notification that "Apple could not verify "Excalibur" is free of malware".
    
    <div className="w-full">
    <div className="mx-auto max-w-64">
    <Image img={require("./img/macos/not-opened.png")} alt="Excalibur Not Opened Alert" />
    </div>
    </div>

    You will need to manually allow the app to open. On recent macOS versions, this can be done by following these steps:

    1. Open System Preferences > Privacy & Security.
    2. Scroll down until you see a message like "Excalibur was blocked to protect your Mac." <Image img={require("./img/macos/blocked-to-protect.png")} alt="Blocked to Protect" />
    3. Click "Open Anyway". You might need to enter an administrator's password.
    4. Excalibur should open.

    Subsequent launches should not need to repeat this process.

    :::

    </TabItem>

    <TabItem value="linux" label="Linux">

    The Linux client can be obtained as either a `.deb` file or an `.AppImage` file.

    <Tabs groupId="linux-file">
        <TabItem value="deb" label=".deb">
            1. Download the `.deb` package from <a href="/download?id=app-linux-deb" target="_blank">here</a>.
            2. In the same directory as the downloaded file, run
               ```bash
               sudo apt install ./<file>.deb
               ```
               where `<file>` is the name of the downloaded file.
            3. Start Excalibur by running the command
               ```bash
               excalibur-electron
               ```
               in a terminal.
        </TabItem>

        <TabItem value="appimage" label=".AppImage">
            An [AppImage](https://appimage.org/) allows you to run Excalibur without installation or the need for root rights.

            1. Download the `.appimage` package from <a href="/download?id=app-linux-appimage" target="_blank">here</a>.
            2. Make the AppImage executable by running
               ```bash
               chmod a+x ./<file>.AppImage
               ```
               where `<file>` is the name of the downloaded file.
            3. Start Excalibur by running
               ```bash
               ./<file>.AppImage
               ```
        </TabItem>
    </Tabs>

    </TabItem>

    <TabItem value="android" label="Android">
    The Android client is an Android app in the form of an `.apk` file.

    1. Download the Android app from <a href="/download?id=app-android-apk" target="_blank">here</a>; you should now have an `.apk` file.
    2. Copy the `.apk` file to your Android device.
    3. Install the app on your Android device.
        - Do note that you may need to enable installation from unknown sources on your Android device in order to install the `.apk` file.

    :::warning

    It is recommended to *disable* the installation of unknown sources on your Android device after installing the app.
    
    :::

    </TabItem>

    <TabItem value="pwa" label="Progressive Web App (PWA)">
    
    The PWA distributable is simply a zip file containing all the web assets to run a PWA.

    1. Download the PWA distributable from <a href="/download?id=app-pwa" target="_blank">here</a>.
    2. Extract the contents of the zip file to a folder of your choice. It should contain a `dist` folder. This is the PWA.

    By running a HTTP server and serving the files in `dist`, you can access the PWA. For example, using Python, you can run

    ```bash
    python -m http.server 8080
    ```

    within the `dist` folder to serve the files. Navigating to [`http://localhost:8080`](http://localhost:8080) should bring you to the PWA.

    :::warning

    The above Python command is not safe for production use. It is only for trying out Excalibur via a PWA.

    :::

    </TabItem>
</Tabs>

## Onboarding

Upon opening the app, you will be greeted with the following screen:

<Image img={require("./img/welcome.png")} alt="Welcome Screen" />

Click on "Continue".

At this stage, one of two things might happen. If you started the server on `localhost`/`127.0.0.1` with the default port (i.e., `52419`), you should be automatically redirected to the login page. What happened is that the app autodetected a running Excalibur server instance on the host and thus set the server URL automatically. In this case, you can go straight to [creating a new user](#creating-a-user).

Otherwise, you should see a screen that allows you to enter a server URL:

<Image img={require("./img/server-choice.png")} alt="Server URL Screen" />

Enter the server URL in the provided text field. For example, if you are running the server on your local machine with port `8888`, enter `http://localhost:8888` and click "Continue".

## Creating a User

You should now see a login screen.

<Image img={require("./img/login.png")} alt="Login Screen" />

Click on "Sign Up". You should now see this page.

<Image img={require("./img/sign-up.png")} alt="Sign Up Screen" />

Enter your desired username and password into the fields. You can optionally choose to enable or disable obfuscated names. If enabled, this means that the names of the files on the server would be obfuscated, making it harder for others to guess what files you have stored. **The names of the files on the client-side remain unchanged.**

To finish creating the user, you will also need to provide the Account Creation Key (ACK) Mnemonic of the server. The mnemonic can be retrieved by running the command
```bash
excalibur user ack
```
on the server.

:::tip

You can just copy and paste the 24-word mnemonic into the first text box. This is especially convenient if you are running the server on the same machine as the client.

:::

Once you have entered the mnemonic, click "Confirm". If the ACK was entered correctly, you should see a new pop up titled "Vault Key":

<div className="w-full">
<div className="mx-auto max-w-100">
<Image img={require("./img/vault-key-initial.png")} alt="Vault Key Screen" />
</div>
</div>

This key is the actual key used to encrypt your data. Actually, what is shown is the vault key mnemonic, similar to that of the ACK mnemonic that you entered. It is ***extremely unlikely*** that you will need to use this key, but it is recommended to keep it in a secure location.

:::important

Please ***scroll down*** on the pop-up to see the full vault key mnemonic. You can click on the copy button on the right of the warning at the top to copy it to your clipboard.

:::

Once you have saved this key, click the "X" button to close the pop up. You should be redirected to the files explorer.

Congratulations! You have successfully set up a client to connect to an Excalibur server. Move on to learn what the [interface](../interface.mdx) looks like.
